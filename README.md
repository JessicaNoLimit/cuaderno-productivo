📝 Cuaderno Productivo

✏️ Una libreta digital interactiva para organizar tareas, guardar pensamientos y marcar favoritos.
Proyecto práctico del Módulo 3 (HTML - La estructura de tu web) desarrollado con HTML, CSS y JavaScript.

✨ Características

📝 Gestión de tareas

🧠 Espacio para memorias y sueños

⭐ Sistema de favoritos con límite dinámico

🎨 Diseño inspirado en una libreta clásica

💻 Manipulación del DOM con JavaScript vanilla

🛠️ Tecnologías utilizadas

HTML5 (estructura semántica)

CSS3 (estilos personalizados y diseño visual)

JavaScript (lógica e interacción dinámica)
